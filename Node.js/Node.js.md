Se trata de un nuevo entorno de ejecución para **<font color="#f79646">JavaScript</font>**, que en lugar de ejecutarse en un navegador como se hace tradicionalmente, ahora permite hacerse como una aplicación del sistema, permitiendo cosas locas como servidores, o aplicaciones raras.

Aunque cuando se habla tradicionalmente de **<font color="#9bbb59">Node.js</font>**, se refieren principalmente a su papel dentro del desarrollo de servidores, cabe resaltar que gracias a su casi infinita librería de paquetes, ahora se permiten hacer miles de cosas con el, expandiendo las posibilidad de JavaScript hasta el cielo.
